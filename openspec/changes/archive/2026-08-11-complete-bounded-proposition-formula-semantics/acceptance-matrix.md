## Production scope guard

允許新增或修改的 production surfaces 僅為 proposal `Impact` 已列出的：單一 opaque `PropositionExpression`、`ClassicalSemantics`、`TruthFunctionSynthesis`、`UnicodeNormalizationV1` 與 generated／vendored trust chain、既有 projection／question／display-safe 整合，以及必要的 `Package.swift` 接線。

下列項目不在本 change，任何 RED test 也不得要求其 production symbol：

- 量化、變項束縛、模態、機率或 SAT／SMT 求解器。
- 第二套 `Formula`／`Negation.swift` AST 或 strong-Kleene evaluator。
- `constant` expression case；零元 function table 只能被表示，不能被 synthesis 成 constant node。
- caller-adjustable depth、node、atom、row、completion、rewrite 或 synthesis limits。
- semantic normalization、De Morgan rewrite API、AST 最小化或 hash collision-free 保證。
- context-free epistemic evaluation、store-independent evidence推論，或把 classical table 當成 snapshot truth。
