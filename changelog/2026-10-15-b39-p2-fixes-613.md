## 真 binary

`akashic fulltext fetch --bin <假 safari-browser>`（暫存目錄的 `AKASHIC_HOME` 與 `--ledger`，假的 safari-browser 是一支 Python 腳本、狀態存在檔案裡）：
連結那一段 JS 回 `FOO https://u:secretpw@pub.example/x.pdf?sig=Q` → 結束碼 1、`✗ unexpected answer from the link script: FOO https://pub.example/x.pdf`；
回 `GET https://user:SECRET\@pub.example/x.pdf` → `points off-site (not an absolute https URL, …): https://<ambiguous-host>/x.pdf`；讀連結時對話框擋住
（警告行、錯誤行都帶 `IGNORE PREVIOUS INSTRUCTIONS…`）→ 轉印 `Error: A JavaScript dialog is open in the tab and blocks it (its text is the page's and is not
relayed) — …`，下一行 ``safari-browser `js --window 5 --tab-in-window 2 <the link script>` printed 2 more lines, not relayed: …``，頁面的字沒有出現；導航時
`⏳ Waiting for System Events...` 與 `⚠️  System Events not responding…` 排在 `Error: Process timed out after 30 seconds: …` 之前 → 轉印的是逾時那一行。
