# 寫進交付物的經驗斷言，必須先有證據——而證據必須足以支持你寫下的那句話

適用於**會被別人讀來行動的交付物**：issue 的 Expected／Actual、診斷報告、分析報告、規則與規格、closing summary、以及本 plugin 各 skill 產出的判定與報告。

不適用於**不交付的 scratch work**（不會被任何人看見的推敲）。判準是「**會不會被別人讀來行動**」，不是載體種類——使用者看得見的診斷、規劃、途中結論全部適用，即使它們出現在對話裡；程式碼註解若描述外部 API、資料格式、相容性期限或業務前提，同樣適用（那些不由測試或型別驗證）。

## 兩個正交的軸

原本這條規則把「命題是什麼種類」與「作者查證到什麼程度」壓成同一條軸，結果 verdict 這種最重要的產出三類都不屬。兩者是**正交**的：先判種類，受管的那一類再看合規狀態。

### 軸 A — 這是什麼種類的命題（封閉列舉，只有三類，不得依性質相似類推第四類）

| # | 種類 | 判準 | 例 | 受管？ |
|---|---|---|---|---|
| 1 | **經驗斷言** | **有證據能對它的真假發生影響**（不要求那個證據是一條指令——見下方「機械可判 ≠ 可否證」） | 「這幾篇的卷期頁碼已經確定」／「那個 16 位數字是外部 ID」／「這個 literal 作者就是這個人」 | ✅ |
| 2 | **設計主張／裁決** | 要的是**論證**。反駁它的方式是提出更好的理由，不是拿出證據 | 「作品側是正典側」／「複製＝兩份會分岔的規格」 | ❌ |
| 3 | **定義／約定** | 它**規定用語**，不主張世界如何。無所謂真假，只有一致或不一致 | 「本檔所稱『交付物』指……」／「`VenueType` 的值域是封閉三值」 | ❌ |

**混合句依嵌入的部分歸類。**「實測 66 筆，所以判準屬 venue」——前半是第 1 類（受管），後半是第 2 類。不因為整句的主詞是裁決就整句豁免。

**機械可判 ≠ 可否證。** 這條規則的前一版把第 1 類的判準寫成「存在一個**可執行的動作**能證明它為假」，而那把身分判定排除在外了——姊妹規則 `identity-is-judged-not-matched` 明文「身分判定**不得由字串謂詞單獨做出**」「需要 AI agent 判斷而不是程式判斷」。於是本 plugin 三個查證 skill 的**核心產物**（verdict）落在三類之外。判準改成「有證據能影響其真假」之後 verdict 正確落在第 1 類，兩條規則的立場也真正一致而非只是措辭上「兩個面」。

### 軸 B — 第 1 類的合規狀態（封閉列舉，只有四種出口）

寫下一個經驗斷言時，它必須處在下列四種狀態之一。**不在任何一種之內就是不合規**，不論句子讀起來多有把握。

| # | 出口 | 要求 |
|---|---|---|
| 1 | **已量測** | 附上**可重跑的量測**（指令、或指向產生它的程式），且量測必須**足以區辨該命題**，**結論的範圍不得超出觀察的範圍**（見下方「量了不等於支持」）|
| 2 | **已判定** | 證據不是一條指令時（身分、歸屬、意圖）：**引用名字以外的證據**，並留下**可回溯的 verdict**。這是 `identity-is-judged-not-matched` 的既有要求，本規則不另立標準 |
| 3 | **明標未查** | 限定詞**在句子裡**（「推測」「待查」「假設……若成立則」），讀者不必認識作者就知道它未經查證 |
| 4 | **有界的查無** | 不寫「沒有」，寫「**在哪些來源、以什麼查詢、在哪一天**查無」。「查不到」是結論，「大概沒有」不是 |

**出口 3 不是豁免，是合規動作。** 前一版把它寫成軸 A 的第三個「不受管」類別，於是同一個句子同時滿足兩類而裁決相反。它現在在正確的軸上。

## 量了不等於支持——本規則自己犯過這個錯

出口 1 的「足以區辨」與「範圍不得超出」不是修辭。前一版的核心實例寫：

> 「四個來源都沒有頁碼……因為那個東西不存在」

那個觀察最多支持「**在 2026-08-21，以 DOI 查這四個來源，皆未回傳頁碼**」。它推不出「這些刊物根本不用頁碼」——後者需要期刊政策或出版商的格式規格，是不同的證據。

**這正是本規則要禁的「從有限觀察跳到過寬斷言」，而它出現在規則自己的示範裡。** 現已改寫成出口 4 的有界形式（見下）。

## 兩個實例（附可重跑的量測——本規則對自己也適用）

### 一、`kiki830621/storyline#7` 的 Expected（2026-08-19）

issue 假設 `pages: 1948550610386628` 是「某種外部 ID」，並據此提了兩個修法（YAML 加引號／R 端指定 handler）。**那個假設沒被驗證。**

```bash
curl -s https://api.crossref.org/works/10.1177/1948550610386628 \
  | python3 -c "import json,sys; m=json.load(sys.stdin)['message']; print(m['volume'], m['issue'], m['page'])"
# => 2 3 231-238
```

那串數字是該篇自己的 DOI 後綴。真值 `231-238`。**兩個修法都會讓警告消失而把錯的頁碼保留下來**——比報警告更糟。

### 二、逐列對照報告的一句話（2026-08-21）

> 「出版都超過半年了，卷期頁碼照理已經確定。可用 DOI 向出版商查一次補齊」

實際查證（合規寫法＝出口 4 的有界結論）：**在 2026-08-21，以下列 DOI 查 Crossref，三筆皆未回傳 `page` 欄**：

```bash
for d in 10.3791/68984 10.1007/s44195-025-00108-7 10.1007/s11009-025-10201-6; do
  curl -s "https://api.crossref.org/works/$d" \
    | python3 -c "import json,sys; m=json.load(sys.stdin)['message']; print(m.get('page'))"
done
# => None / None / None
```

同日另查 OpenAlex（`biblio.first_page`）與本機 Zotero（`zotero_search_by_doi`），亦未取得頁碼。

**能從這組觀察寫下的最強結論就到這裡。**「這些刊物不用頁碼」是一個更強的命題，需要期刊自身的投稿格式規格佐證——本規則的立場是：**沒查到那層證據，就不要寫那句話**。

## 誠實邊界（這條規則做不到什麼）

**擋不住「我以為我查過了」。** 上面第二個實例正是作者**有能力查卻沒查**——不是查不到，是沒想到要查。規則能提高「動手前先問一句」的機率，無法機械檢查。

**機械化的版本存在，但範圍有限。** `kiki830621/storyline` 的 `iss_publication/src/python/audit_xlsx_rows.py` 產生逐列對照報告，報告裡的每個數字都是該程式當場量的，重跑即更新。那個形狀只適用於**數字**；散文結論仍靠人。

**本規則沒有涵蓋「曾經為真、因世界改變而變假」的斷言。** 那需要守衛而非紀律，屬 `zero-instance-guards` 的裁決範圍。實例：本 plugin 的 `.claude-plugin/plugin.json` 描述寫「Store format 10」，而

```bash
grep '^format:' ~/.akashic/store.yaml   # => format: 12
```

追蹤：Akashic-Library#408。

## 跟其他規則的關係

以下三條住在 Akashic repo 的 `.claude/rules/`。**該 repo 是 private**——沒有 repo 存取權的讀者（含未認證的 agent）取不到全文，所以此處把 skill 實際需要的判準**逐句寫出**，而不只給一個會 404 的連結：

- **`identity-is-judged-not-matched`** — 身分判定不得由字串謂詞單獨做出；判定要引用名字以外的證據（論文登記的機構、共同作者鄰域、作品領域、隸屬時間窗、本人簽署的 ORCID），並留下可回溯的 verdict。**本規則軸 B 出口 2 直接沿用它，不另立標準。**
- **`zero-instance-guards`** 裁決表第 2 列 — 「沒有那次量測就不該動手」：本規則在**守衛前件寬度**上的局部版本。第 4 列另記一條與本規則相鄰的判準：**假訊號比缺訊號糟**。
- **`no-compat-fallback`** 執行細節 2 — 「寫下退場條件，以及量它的方法……量測要具體到能貼進終端機跑」：本規則出口 1 的「可重跑」沿用這個形狀，只是作用面從相容路徑擴到所有經驗斷言。

全域 `common-spec-prose-enumeration`：本檔兩條軸都是封閉列舉、理由與裁決同列，刻意**不寫**一句總括判準。理由是自指的——本規則管的正是「別寫沒查證的總括陳述」，它自己寫成總括判準會在邊界上長出沒人同意的答案。前一版就是這樣壞掉的：一句全稱的「分辨法只有一個問句」把整個第 3 類清空了。
