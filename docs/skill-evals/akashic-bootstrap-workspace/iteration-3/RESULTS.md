**評測用模型的優先序（使用者裁示）：sonnet 優先，其次 opus，haiku 不採信。**
haiku 的結果只當佐證，不作主證。

**結論翻轉**：sonnet 與 opus 讀舊版都沒有失敗。先前「這是 skill 的效果」的判斷**錯了**——haiku 的失敗是模型能力，不是 skill 缺漏。

skill 在 sonnet 上的作用只是把「待人工判定」變成「明確排除」（處置的果斷度），以及對 Fischer K 更保守（舊版判「是」、新版判「需人工判定」）。**那不是正確性差異。**

### baseline 抓到我加的內容裡的一個實質錯誤

opus + 舊版指出：`@gate.sinica.edu.tw` 是中研院的**院級共用網域**，跨所通用，**分不出植微所與統計所**。而我在新版寫「用 email domain 確認」——那是錯的。已修正為「多半沒有鑑別力，只有所級網域（如 `@stat.sinica.edu.tw`）才是證據」。

## 結論：分界線是「模型推得出來 vs 推不出來」

- **推得出來**（推理）：更正記錄的用途、標題滿分但其他訊號不合取 → 舊版自己就到得了。寫成規則只讓 agent 多一句引用，判斷本身沒變。
- **推不出來**（領域事實）：TIGP 是該所主辦的學程 → 模型沒有理由知道，錯誤形狀與人類初次作業時一致。
